# StorageCleaner — Homebrew tap

```bash
brew install --cask snvladm/storagecleaner/storagecleaner
```

The app is not notarized yet: on first launch macOS shows “Apple could not verify…” — open System Settings → Privacy & Security → “Open Anyway”.
Or install without the quarantine flag: `brew install --cask --no-quarantine snvladm/storagecleaner/storagecleaner`.

Updates: `brew upgrade --cask storagecleaner` (the app also updates itself).
